Wanderlust – Travel & Tour Booking Landing Page

A Responsive Tourism Website built using HTML & CSS

 Overview

Wanderlust is a fully responsive travel & tour booking landing page designed using only HTML and CSS.
It focuses on clean UI/UX, semantic HTML, accessibility, and modern layout techniques such as Flexbox, Grid, reusable components, and responsive design.

 Purpose of the Project

Build a modern tourism landing page with professional UI.

Practice semantic HTML5 structure.

Use Flexbox & CSS Grid for layout.

Create reusable components (cards, forms, testimonials, FAQ).

Ensure full responsiveness on all devices.

Implement an accessibility feature: Skip to Main Content.

Maintain a consistent color & typography design system.
